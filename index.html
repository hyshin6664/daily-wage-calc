세금 = 소득세 3% + 지방세 0.3% (각각 10원 미만 버림) · 주휴수당 = 한 주(월~일) 소정근무일 100% 출근 시 8시간 가산
# 이름 월급(원)
입력 시 시급 자동		 시급(원)
월÷209		 입사일 종료일 근무일수 실근로시간 주휴시간
수정 가능		 합계시간 세전급여 소득세
3%		 지방세
0.3%		 공제합계 차인지급액
합계 0 0 0 0 0
· 월급을 입력하면 시급은 ÷209(고용노동부 표준 월 소정근로시간)로 자동 계산됩니다. 예: 2,200,000 → 10,526원.
· 월급을 비우면 시급을 직접 입력할 수 있어요.
· 입사일 = 첫 출근일, 종료일은 비워두면 그 달 말일로 자동 계산됩니다.
· 엑셀 다운로드 후 다시 불러오면 같은 인원이 그대로 복원됩니다.
· 주휴시간은 자동(소정근무일 100% 출근 시 8h/주) 표시됩니다. 연속근무로 마지막 주에도 줘야 하는 등 직접 수정해야 할 때는 칸을 클릭해 입력하세요. 비우면 자동값으로 돌아갑니다.
