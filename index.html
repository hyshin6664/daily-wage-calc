주휴수당 = 한 주(월~일) 근무시간 15h 이상일 때 비례 가산 (주시간÷40×8h, 최대 8h) · 주휴 칸 직접 수정 가능
# 이름 월급(원)
시급 자동		 시급(원)
월÷209		 근무일
달력에서 선택		 1일 시간
개인별		 근무일수 실근로시간 주휴시간
수정 가능		 합계시간 세전급여 소득세
3%		 지방세
0.3%		 공제합계 차인지급액
합계 0 0 0 0 0
· 월급을 입력하면 시급은 ÷209(고용노동부 표준 월 소정근로시간)로 자동 계산됩니다. 예: 2,200,000 → 10,526원.
· 근무일 칸의 버튼을 누르면 달력이 열립니다. 그 달에 출근한 날을 클릭해서 ✓ 표시. 빠른 채우기(평일 전체/이번달 전체) 버튼도 있어요.
· 주휴시간은 자동 비례 계산: 주 15h 이상이면 (주시간÷40×8h), 최대 8h. 예: 주 32h → 6.4h. 직접 수정 가능, 비우면 자동 복귀.
· 엑셀 다운로드 후 다시 불러오면 같은 인원·근무일이 그대로 복원됩니다.

근무일 선택

· 시작·종료일 사이에서 선택한 요일만 골라 한 번에 채워줍니다.
· 예: 시작 5/12 ~ 종료 5/31, 월~금 → 그 기간의 평일만 자동으로 ✓ 표시.
· 적용 후 일별 탭에서 추가/제거 가능합니다.
