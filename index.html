세금 = 소득세 3% + 지방세 0.3% (각 10원 미만 버림)
주휴수당 = 한 주(월~일) 근무시간 15h 이상일 때 8h 자동 가산 · 주휴 칸 직접 수정 가능
# 이름 월급(원)
시급 자동		 시급(원)
월÷209		 근무일
달력에서 선택		 근무일수 실근로시간 주휴시간
수정 가능		 합계시간 세전급여 소득세
3%		 지방세
0.3%		 공제합계 차인지급액
합계 0 0 0 0 0
· 월급을 입력하면 시급은 ÷209(고용노동부 표준 월 소정근로시간)로 자동 계산됩니다. 예: 2,200,000 → 10,526원.
· 근무일 칸의 버튼을 누르면 달력이 열립니다. 그 달에 출근한 날을 클릭해서 ✓ 표시. 빠른 채우기(평일 전체/이번달 전체) 버튼도 있어요.
· 주휴시간은 자동(주 15h+ 이면 +8h) 표시됩니다. 직접 수정해야 할 때는 칸을 클릭해 입력, 비우면 자동으로 돌아갑니다.
· 엑셀 다운로드 후 다시 불러오면 같은 인원·근무일이 그대로 복원됩니다.
